# LTEE variant calling

Variant calling on LTEE E. coli samples

Author: mohiraa M

## Reproduce the results

You need [Pixi](https://pixi.prefix.dev/latest/) and an internet connection.
Then, from this folder:

```bash
pixi install          # builds the exact environment recorded in pixi.lock
pixi run reproduce    # downloads the raw data and rebuilds every result
```

`pixi run reproduce` must work on a fresh clone of this repository. A GitHub
Action (`.github/workflows/reproduce.yml`) checks that on every push.

## What is where

| Folder | What goes in it | Rule |
|--------|-----------------|------|
| `data/raw/` | Data exactly as you received it | Read-only. Never edit; download it with a script. Not committed. |
| `data/processed/` | Data derived from raw data | Regenerated by code. Not committed. |
| `metadata/` | Sample sheet, data sources, checksums, data dictionary | Small text files, committed. |
| `scripts/` | Code you write (Python, shell) | Committed. |
| `config/` | Parameters for the analysis or workflow | Committed. |
| `workflow/` | Snakemake and Nextflow pipelines | Committed. |
| `notebooks/` | Jupyter notebooks for exploration | Committed, outputs cleared or small. |
| `reports/` | Quarto documents that turn results into a report | Source committed, rendered HTML not. |
| `results/` | Figures, tables, logs made by the code | Regenerated. Not committed. |
| `docs/` | Longer documentation | Committed. |
| `envs/` | Conda `environment.yml` exports, for people without Pixi | Generated from `pixi.toml`. |
| `containers/` | Dockerfile and Apptainer recipe | Committed. |

Each folder has its own `README.md` with more detail.

## Data availability

Raw reads are in the NCBI Sequence Read Archive under BioProject PRJNA295606
(runs SRR2589044, SRR2584863, SRR2584866). The subset used here is on figshare,
<https://doi.org/10.6084/m9.figshare.7726454> (CC0). The reference genome is
*E. coli* B str. REL606, GenBank CP000819.1 (NCBI). Run
`pixi exec python scripts/download_data.py` to download and verify the raw data;
all derived data and results are regenerated from it by the code in this
repository. Code and environment: GitHub repository (MIT), to be archived on
Zenodo with a DOI.
